JSON 基礎知識

數據類型

  • "鍵" 字串（必須用雙引號）
  • "值" 字串（雙引號）
  • 123 數字
  • true / false 布林值
  • null 空值
  • [] 數組
  • {} 對象

常見錯誤

  • 使用單引號代替雙引號
  • 對象或數組後有多餘逗號
  • 鍵名未用引號包圍
  • 未轉義的特殊字符
  • 註釋（JSON 不支援註釋）
  • 尾隨逗號
